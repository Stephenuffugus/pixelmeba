# Pixelmeba — content rating notes (Play Console → Policy → App content → Content rating, IARC questionnaire)

App version 1.0.0. Fill the questionnaire with the email address that should receive the IARC certificate.

## Category

Choose **Game** (the questionnaire's "All Other App Types" does not fit: Pixelmeba is a simulation game).

## Answers, question by question, with the reason

| Topic | Answer | What is in the app |
|---|---|---|
| Violence | **No** realistic, fantasy or cartoon violence against characters | The organisms are abstract pixel cells. Some eat others (a consumer engulfs a cell, a phage infects a host, a parasite rides a host); a cell that dies leaves remains that dissolve into the dish. No blood, no gore, no weapons, no human or animal characters, nothing a player attacks. |
| Blood / gore | **No** | — |
| Fear / horror | **No** | A quiet optional ambient sound and soft cues; nothing startles. |
| Sexual content, nudity | **No** | Cells divide (split in two); nothing else. |
| Language (profanity, crude humour) | **No** | All text is fixed; the only player text (dish names, nicknames, notes) stays on the device and is never shown to anyone else by the app. |
| Controlled substances (drugs, alcohol, tobacco) | **No** | Yeasts appear as fictional organisms; there is no alcohol, brewing or drug content. |
| Gambling (real or simulated) | **No** | No chance-based rewards, no betting, no loot boxes. Randomness is the simulation's own and is seeded. |
| Users can interact or exchange content | **No** | No chat, no online play, no accounts, no user profiles. |
| Shares user location | **No** | The app has no location permission. |
| Allows users to purchase digital goods | **No** | A paid app ($0.99) with **no in-app purchases**. |
| Unrestricted internet / web browser | **No** | The app makes no network requests and opens no web pages. |
| Ads | **No** | No advertising of any kind. |
| User-generated content shared online | **No** | Sharing creates a file (a picture, a starting recipe or a living dish) that the player sends with the system share sheet to an app they choose; Pixelmeba hosts and shows nothing online. |
| Is the app a news, educational or reference app primarily? | **No** (a game) | It teaches by play, but every organism, rate and chemical is a fictional game rule. |

## Expected rating

**Everyone** (ESRB) / **PEGI 3** / **USK 0** / **IARC 3+**. If a region returns a higher rating, record which
answer drove it in `docs/EXPANSION_RESPONSE.md` §7 before changing anything.

## Target audience and content (Play's separate "Target audience" page)

Recommended: **13 and over** (or "Everyone, not designed for children"), unless the owner chooses to enrol in
Designed for Families (extra review; no ads and no data collection already hold). The store listing must not
target children with its wording or art if Families is not chosen (`store/listing.md` does not).
